Parcours professionnel

Stagiaire Data Engineer – Analyse intelligente & détection de fraude

SRM-RSK, Société Régionale Multiservices Rabat-Salé-Kénitra, du 3 juillet au 3 septembre 2026

Contexte

La SRM-RSK distribue l’eau et l’électricité dans la région de Rabat-Salé-Kénitra. Pendant deux mois, j’ai conçu une plateforme qui aide les équipes de contrôle à repérer les clients dont la consommation est suspecte.

Mission

Analyser les profils de consommation des clients, détecter automatiquement les comportements frauduleux et les branchements illégaux, puis produire des rapports exploitables sur le terrain.

Ce que j’ai réalisé

  • Préparation des données et construction de variables décrivant le comportement de consommation de chaque client
  • Entraînement de modèles de machine learning (XGBoost et Random Forest) pour repérer les fraudes et les branchements illégaux
  • Tableau de bord interactif avec Streamlit : indicateurs clés, graphiques et recherche d’un client par nom
  • Génération automatique de rapports PDF avec FPDF2, destinés aux équipes de contrôle
  • Mise en place d’une connexion sécurisée pour réserver l’accès aux personnes autorisées

Python, Streamlit, XGBoost, Random Forest, FPDF2, Plotly, SQLite, Git

Projets

Plateforme d’analyse de consommation et de détection de fraude

Stage SRM-RSK, 2026

Objectif

Donner aux équipes de contrôle de la SRM-RSK un outil unique pour analyser la consommation des clients, repérer les fraudes et les branchements illégaux, et préparer leurs interventions grâce à des rapports prêts à imprimer.

Fonctionnalités

  • Tableau de bord avec des indicateurs clés : nombre de clients, cas de fraude, impayés d’eau et impayés d’électricité
  • Graphiques interactifs sur les profils de consommation
  • Recherche d’un client par nom, avec son identifiant affiché pour distinguer les homonymes
  • Détection automatique des comportements suspects par des modèles XGBoost et Random Forest
  • Rapports PDF générés automatiquement pour les équipes de contrôle
  • Page de connexion et d’inscription, avec mots de passe hachés (PBKDF2-SHA256 avec sel) et base SQLite

Réalisation

Le code est organisé en modules séparés (préparation des données, variables, modèle, rapports, authentification) autour d’un tableau de bord Streamlit. Le projet est versionné sur un dépôt GitHub privé, sans le jeu de données volumineux.

Python, Streamlit, Plotly, XGBoost, Random Forest, FPDF2, SQLite, Git

Contrôle d’accès par reconnaissance faciale en temps réel

Projet académique, 2026

Objectif

Autoriser ou refuser l’entrée d’une personne en reconnaissant son visage à partir d’un flux vidéo en temps réel.

Principe

Des réseaux de neurones convolutifs reconnaissent les visages. Une API les expose et une interface web affiche le résultat.

Ce que j’ai réalisé

  • Mise en œuvre de trois architectures de deep learning : VGG19, ResNet50 et MobileNetV2
  • API avec FastAPI pour relier les modèles à l’application
  • Interface React pour utiliser le système en direct

Python, TensorFlow, Keras, VGG19, ResNet50, MobileNetV2, FastAPI, React
